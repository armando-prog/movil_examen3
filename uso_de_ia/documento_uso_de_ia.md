## Descripción del proyecto

FitTrack Pro es una aplicación móvil multiplataforma para registrar el peso corporal en kilogramos junto con su fecha. El formulario valida que la fecha no esté vacía y que el peso sea numérico y mayor que cero; los registros aparecen en una lista. Se conservan en memoria mientras la aplicación está abierta: no hay persistencia en una base de datos.

## Revisión y validación

El proyecto incluye pruebas de interfaz para la lista vacía inicial, el alta de un registro válido y el rechazo de un peso igual a cero. El equipo debe revisar el código y ejecutar las pruebas: una sugerencia de IA no garantiza que el resultado sea correcto ni sustituye la validación humana.
